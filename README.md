# E-Commerce Orders Analysis | Google BigQuery SQL

## Project Overview
This project analyzes 150 e-commerce order records using Google BigQuery and SQL to understand customer activity, payment preferences, order trends, and delivery performance.

## Dataset
The dataset contains five columns:
- Order ID
- Customer ID
- Order Date
- Order Status
- Payment Method

## Business Analysis
- Overall order KPIs
- Order status and cancellation analysis
- Payment method preferences
- Customer order behavior
- Monthly and yearly order trends
- Advanced SQL analysis

## Tools & Technologies
- Google BigQuery
- SQL
- GitHub

## SQL Concepts
SELECT, WHERE, GROUP BY, ORDER BY, CASE, JOIN concepts, CTEs, aggregate functions, date functions, and window functions.

## Project Objective
To develop practical SQL skills and generate meaningful business insights from e-commerce order data.

## Note
This dataset does not contain product prices or quantities. Therefore, revenue and profit analysis are outside this project's scope.
